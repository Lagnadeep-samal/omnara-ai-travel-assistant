# AI Travel Planner

AI-powered travel planner using:

- LangChain
- LangGraph
- Flask
- Groq
- Tavily Search

---

# Features

- Cheap hotel recommendations
- Tourist place suggestions
- Travel budgeting
- Weather information
- Real-time web search

---

# Install

```bash
uv add -r requirements.txt
```

---

# Run

```bash
python app.py
```
